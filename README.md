# Portfolio Profissional | Saulo Pavanello

Landing page profissional para apresentação de serviços e portfolio como desenvolvedor Front-End. Este projeto foi desenvolvido com React e Vite, com foco em design atraente, animações suaves e experiência de usuário de alta qualidade.

## 🚀 Características

- **Design Elegante**: Interface moderna em preto e dourado com animações responsivas
- **Seções Intuitivas**:
  - Hero com animações de partículas e efeitos visuais
  - Seção "Minha Abordagem" destacando três pilares de serviços
  - Portfolio dinâmico com projetos, resultados mensuráveis e depoimentos
  - Informações de contato direto e links para redes sociais
- **Performance Otimizada**: Tempo de carregamento rápido e experiência fluida
- **Responsividade Total**: Adaptação perfeita para todos os dispositivos

## 🛠️ Tecnologias Utilizadas

- React 19
- Vite 6
- CSS Modules para estilização
- Font Awesome para ícones
- Animações CSS customizadas

## ⚙️ Instalação e Uso

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/proposta-portfolio.git
cd proposta-portfolio
```

2. Instale as dependências:

```bash
npm install
```

3. Execute o projeto em modo de desenvolvimento:

```bash
npm run dev
```

4. Para gerar a versão de produção:

```bash
npm run build
```

## 🌐 Implantação

Após executar `npm run build`, o projeto estará pronto para implantação na pasta `dist/`.

Para uma implantação rápida, você pode usar:

```bash
npm run deploy
```

## 📝 Customização

O projeto foi construído com modularidade, permitindo fácil customização de:

- Esquema de cores (principalmente em arquivos CSS)
- Textos e conteúdo (componentes React)
- Projetos e depoimentos (componente Portfolio)
- Informações de contato (componente Contact)
